言字 (Yana) 0.3.0。Typlus 从这个版本起改名为言字，英文名 Yana。

## 新功能

- **全新界面**：录音胶囊、菜单栏、设置、历史记录和首次启动引导都重新设计了。第一次打开会有引导，一步步开权限、填 Key、下载模型，最后当场试一句。
- **中英双语**：设置 › 通用 › 界面语言，可以跟随系统，也可以固定中文或 English，切换后立刻生效。
- **历史记录**（⌘Y）：每次听写的原文、润色结果和耗时都能找回来，误识别的词一键加进词库。
- **改写选中的文字**：先选中文字再按 F5，说出要求，比如“改得更正式”“翻成英文”。
- **用量**：每天听写了多少次，大概花了多少钱。
- **长录音**：单次最长 15 分钟，最后一分钟可以再延长。
- **录音时自动暂停**正在播放的音乐和视频。
- **在中国大陆**：模型自动从国内镜像下载，新安装默认用 DeepSeek 润色。
- **诊断信息**：设置 › 通用 › 诊断信息 › 导出。反馈问题时把这个文件发给我，里面不含 API Key，也不含听写历史。

## 修复

- 慢一点的 App 有时贴进去的是上一次复制的内容。
- 小声说话会被当成没有声音。
- 长按右 ⌘、或者按住右 ⌘ 点鼠标时，会误开始听写。
- AZERTY、Dvorak 等键盘布局下，粘贴和撤销按错了键。
- 同时开了两个会重复粘贴；现在第二个会提示已在运行。

## 安装

下载 `Yana-0.3.0.dmg`，打开后把言字拖进「应用程序」。已经用 Apple 公证，双击就能打开。

需要 Apple 芯片的 Mac（M1 或更新），macOS 13 或更高。

从 Typlus 升级：退出并删掉旧的 Typlus.app。`~/.typlus` 里的 Key、词库和历史记录都会保留，已经给过的麦克风和辅助功能权限也不用重新给。

**English**

言字 (Yana) 0.3.0. Typlus is now called 言字, Yana in English.

- A redesigned capsule, menu bar, Settings, History and a first-run guide.
- Chinese or English interface (Settings › General › Language), switched live.
- History (⌘Y) with the raw transcript, the refined text and timings; add a misheard word to the vocabulary in one click.
- Select text, press F5 and say how to rewrite it.
- Usage per day, recordings up to 15 minutes, media paused while recording.
- In mainland China the model downloads from a mirror and new installs start on DeepSeek.
- Settings › General › Diagnostics exports a report with no API keys and no dictation history.
- Fixed: a slow app pasting the previous clipboard, quiet speech dropped as silence, right ⌘ misfires, paste and undo on the wrong key with AZERTY or Dvorak, and two copies pasting twice.

Needs a Mac with Apple silicon on macOS 13 or later. Upgrading from Typlus: delete Typlus.app; your key, vocabulary, history and permissions carry over.
